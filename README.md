# DBIA Choice Pool Comparison Calculator

Snapshot of the Deep Blue / DBIA choice calculator, hosted so it can be opened in a browser.

Rates bundled in this page are as of 2026-11-11, from that morning's LGIP Rates email, with LOGIC and TexSTAR filled from a later scrape after their site redesign.

FOMC meeting dates follow the Federal Reserve calendar (including 2027), last updated October 28, 2026. Past 2026 meetings are omitted because those decisions are already in published yields. Days to maturity can run up to 730 days so a holding period can include the December 8, 2027 meeting.

Each assumed Fed move affects only the competitor pool yield (40% pass-through, starting after that meeting). The Choice term rate stays locked. Meetings after the selected holding period do not change earnings.
